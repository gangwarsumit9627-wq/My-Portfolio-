 # Sumit Kumar | Personal Portfolio Website

Welcome to my personal portfolio website! 👋

This portfolio showcases my introduction, technical skills, projects, education, and contact information. I am an aspiring web developer and a second-year BCA student who enjoys learning new technologies and building websites.

## 📌 About the Project

The **Sumit Kumar Portfolio Website** is a personal website created to present my skills, academic background, projects, and career interests in one place.

It is designed to help recruiters, developers, and potential collaborators learn more about me and connect with me for internship opportunities.

## ✨ Features

- **Personal Introduction:** Displays my name, introduction, and developer roles.
- **Typing Animation:** Automatically cycles through different learning and developer roles.
- **About Me Section:** Provides information about my background and goals.
- **Skills Section:** Displays skill levels using progress bars.
- **Projects Section:** Showcases my portfolio, an Amazon-inspired shopping website, and Java programming projects.
- **Education Timeline:** Presents my academic background.
- **Contact Section:** Provides email, phone, location, and social media information.
- **CV Download:** Includes a button to download my resume.
- **Scroll Animations:** Uses JavaScript and Intersection Observer to reveal sections as users scroll.
- **Navigation Menu:** Provides links to different sections of the portfolio.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout, visual design, and animations.
- **JavaScript** – Typing effect and scroll-based animations.
- **Google Fonts** – Plus Jakarta Sans typography.
- **Git & GitHub** – Version control and project hosting.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd sumit-portfolio
   ```

3. Make sure all required files, including `style.css`, `Image.me.jpeg`, and `Sumit_Kumar_CV.pdf`, are present in the project folder.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
